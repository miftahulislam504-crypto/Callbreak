# ভয়েস চ্যাট: বাস্তব ডিভাইস টেস্ট (Phase 6)

কোড-টেস্ট (`npm test`, server `npm run test:all`, `smoke.ts`) আগেই সবুজ। নিচেরগুলো শুধু আসল ফোনে হয়।
প্রতিটির পাশে ফলাফল লেখো: ✅ / ❌ + নোট। ❌ হলে স্ক্রিন-রেকর্ড বা Render log রাখো।

**আগে:** Render-এ `AGORA_APP_ID` + `AGORA_APP_CERTIFICATE` আছে, log-এ `Voice chat: ON`। নতুন APK: `npx eas-cli build -p android --profile preview`। দুটো ফোন, একটা প্রাইভেট রুম।

## ক. মূল কাজ
| # | টেস্ট | পাস হলে |
|---|---|---|
| 1 | দুজন প্রাইভেট রুমে ঢুকলো | দুজনেরই ভয়েস অটো-জয়েন, মাইক বন্ধ |
| 2 | একজন আনমিউট করলো (প্রথমবার) | মাইক পারমিশন চায়; দিলে অন্যজন শোনে, সবুজ রিং জ্বলে |
| 3 | অন্যের সিটে ট্যাপ → মিউট | ওই প্লেয়ারের শব্দ আসে না; আবার ট্যাপে আসে |
| 4 | লবি → গেম স্ক্রিন বদল | ভয়েস না কেটে চলতে থাকে |
| 5 | ✕ চাপা বা রুম ছাড়া | কানেকশন কাটে; Console usage-এ মিনিট বাড়া থামে |
| 6 | পাবলিক রুম / কুইক ম্যাচ | অটো-জয়েন হয় না; "ভয়েস চালু" ট্যাপে জয়েন |
| 7 | বট নিয়ে একা | ভয়েস বাটন "disabled", ট্যাপে কারণ বলে |

## ছ. রিলিজ বিল্ড
1. `npx eas-cli build -p android --profile production` (AAB; `CB_RELEASE=1` বসে, cleartext বন্ধ হয়)।
2. Play Console → Internal testing-এ আপলোড, দুই ফোনে `ক` অংশ আবার চালাও।
3. Data safety ফর্ম: `docs/PLAY_DATA_SAFETY.md`।
4. Production-এ পাঠানোর আগে `২৩` নম্বর (usage) আবার দেখো।
