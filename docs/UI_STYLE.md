# UI style: one look on every page

The home page is the reference: dark green felt, gold rims, chunky game buttons, Lilita One for titles / buttons / numbers and Rubik for small text.
Everything else uses the same shared pieces, so a new screen looks right without extra work.

| Need | Use | File |
| --- | --- | --- |
| Text / text input | `Text`, `TextInput` from `@/components/text` (never from `react-native`) | `components/text.tsx` |
| Colours | tokens from `constants/palette.ts` (no hex in screens) | `constants/palette.ts` |
| Corner radius, shadow, button tones, dialog frame | `R`, `shadow`, `TONES`, `PANEL_FRAME`, `HUD_PLATE`, `TITLE_SHADOW` | `constants/ui.ts` |
| Buttons | `Button` (any page), `GameButton` (big home / lobby buttons), `PillButton` (header), `Chip` (choices) | `components/kit.tsx`, `components/gameui.tsx` |
| Cards / sections | `Card`, `CardTitle` | `components/kit.tsx` |
| Page top bar | `PageHeader` (or `MenuPage`, which already has it) | `components/kit.tsx` |
| Dialogs, sheets, overlays | `PANEL_FRAME` + `<PanelShine />` as first child | `constants/ui.ts`, `components/frame.tsx` |
| Dim layer behind a dialog | `SCRIM` | `constants/palette.ts` |
| "How to play" text (rules, examples) | `GUIDES` in `lib/rulesContent.ts`, shown by `(tabs)/rules.tsx`; keep it in step with the server engine | `lib/rulesContent.ts`, `components/rules.tsx` |

Rules of thumb:

- Two fonts: Lilita One (display: titles, buttons, scores, card numbers) and Rubik (small text). `Text` maps `fontWeight` to the right family for you (400-600 Rubik medium, 700 Rubik semi-bold, 800-900 Lilita One). Do not set `fontFamily` and `fontWeight` together.
- The game is English only (`lib/i18n.ts` has one dictionary). Button, chip and pill labels are drawn in capitals.
- Dialogs, sheets and overlays enter with `POP_IN` / `SHEET_IN` / `DIM_IN` from `constants/motion.ts`; screens use the router's fade / slide. Keep new motion small.
- Primary action = gold, normal action = green, quiet action = `secondary` (dark), leaving / deleting = `danger`.
- Gold is for emphasis (titles, the picked option, the main button); do not use it for body text.
- A new colour goes into `palette.ts` first, then into the screen.

## Card-room look and sound (menus)

The menus use the same materials as the table: felt, a wooden rim, brass, ivory. Use the shared pieces instead of drawing your own:

- `MenuBackdrop` (kit.tsx): lamp-lit felt, drifting suits (`DriftingSuits` in fx.tsx), edge shadow, gold rail with corner diamonds. `Screen` and `MenuPage` already include it.
- `Card` / `CardTitle`: dark plate with a gold edge and a soft top light. `TablePanel`: felt in a wood rim, for lists that sit "on the table" (public rooms, lobby).
- `Button`, `Chip`, `PillButton`, `GameButton`, `RoundIconButton`: every button taps with `uiTap()` (small buzz + click). Do not call `hapticTap()` alone on a button.
- `GameButton shine pulse` is for the ONE button you most want tapped on a screen (Quick match, Play, Start). One per screen.
- `MenuPage`: two panes in landscape (picked game on the left, options on the right).
- fx.tsx: `Shine`, `Breathe`, `Confetti` (win screens). Animations use `.get()` / `.set()` on shared values (React Compiler).

Sound (`lib/sound.ts`, built on expo-audio):

- `sfx('name')` plays an effect; the names and their files are listed at the top of sound.ts. Volumes: `SFX_GAIN` (change a number, no rebuild of the files needed). Menu music volume: `MUSIC_VOLUME`.
- Files are generated by `python3 scripts/make-sounds.py` into `assets/sounds/` (pure synthesis, no samples to license). Add a sound = add a `make_x()` there, one `require` + one gain in sound.ts.
- Music plays on every screen except `/game` (decided in `_layout.tsx`); players and switches live in `useSound` (profile screen has the toggles, the home header has a mute-all button).
- Table sounds are hooks in `components/table/useTableSounds.ts` (`useTrickSounds`, `useDealSounds`, `useTurnTicks`); your own card plays its sound the moment you tap it (`markOwnPlay`).
- Never let sound throw: everything in sound.ts is wrapped, and `sfx()` is safe to call anywhere.
